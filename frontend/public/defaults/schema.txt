Prompt CV - CV Data Schema

This is the JSON structure expected by the default Handlebars CV template.
Use this as a reference when building your own template or preparing CV data.

== FIELD DESCRIPTIONS ==

header.name         - Full name of the candidate
header.location     - City and country
header.email        - Contact email address
header.phone        - Phone number with country code
header.linkedin     - LinkedIn profile URL (or other professional link)

application.position - Target job title (used for filename and tailoring)
application.company  - Target company name (used for filename and tailoring)

summary             - 2-4 sentence professional summary

experience[]        - Array of work experience entries (reverse chronological)
  .company          - Company name
  .position         - Job title held
  .period           - Employment period (e.g., "2021 - Present")
  .highlights[]     - Array of achievement bullet points

education[]         - Array of education entries
  .institution      - School or university name
  .degree           - Degree title and field
  .period           - Study period

skills[]            - Array of skill categories
  .category         - Category name (e.g., "Programming Languages")
  .items            - Comma-separated list of skills

== TEMPLATE NOTES ==

- The template uses Handlebars syntax: {{header.name}}, {{#each experience}}, etc.
- Create your template in Google Docs using these placeholders
- The generated filename is derived from: header.name + application.position + application.company
- Fields can be omitted if not applicable; the template should handle missing data gracefully
- Users can customize the schema by creating their own template with different fields
